# Мир понарошку

Сайт-отчёт о решении парадоксальной задачи: «Придумай мир, в котором всё стало понарошку. Во что нужно играть, чтобы обрести подлинность?» Два решения: игра в нарушение правил и всеобщий день сурка.

## Что внутри

- `index.html` — вся страница: разметка, стили и немного JavaScript (просмотр плакатов крупно и петля времени ко второму решению). Сборка не нужна.
- `assets/posters/` — фото итоговых плакатов, выровненные и осветлённые. У каждого две версии: `-sm` для страницы и крупная для просмотра, в JPEG и WebP.
- `assets/groundhog.png` — рисунок сурка с первого плаката, вырезанный по контуру. На странице он служит маской, поэтому сам перекрашивается под светлую и тёмную тему.
- `assets/og.jpg` — картинка-превью для ссылок в мессенджерах и соцсетях.

Текст восстановлен по автоматической расшифровке записи и фотографиям плакатов. Расшифровка местами путала слова, поэтому формулировки близки к сказанному, но не дословны.

## Как посмотреть

Открыть `index.html` в браузере.

## Как опубликовать на GitHub Pages

1. В репозитории открыть Settings → Pages.
2. В Source выбрать Deploy from a branch, ветку `main` и папку `/ (root)`.
3. Через пару минут сайт откроется по адресу https://wolkill.github.io/ponaroshku/

Превью ссылки (`og:image`) настроено на этот адрес. Если сайт будет жить в другом месте, поменяйте адрес в `<meta property="og:image">` в `index.html`.
